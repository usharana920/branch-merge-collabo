# usharana920-branch-merge-collabo

Part 1: Local Merge Workflow
· Create a new GitHub repository remotely and clone it to your local system using VS Code.
·Create a new feature branch, make some changes (e.g., update index.html), and commit them.
·Merge your feature branch into the main branch locally.
·Push the updated main branch to the remote repository.

I am having fun building the github project.
Part 2: Remote Merge via Pull Request
·Again, create a new feature branch locally, make new changes, and push this feature branch to GitHub.
·On GitHub, create a Pull Request from your feature branch into the main branch.
·Review and merge the Pull Request through the GitHub interface.
